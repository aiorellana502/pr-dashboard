A signal, not a verdict.

For pull requests, Open means the work is active. Draft means it is not ready for review. Merged means the changes were added to the project. Closed means it ended without those changes being merged. For issues, Open means it is still open for attention. Closed means it was closed, not necessarily fixed.

Human review signals show each reviewer's latest approval or request for changes. They do not tell you whether all required approvals are in place. “Reported checks passed” only covers checks GitHub reported. It does not mean every required check ran. A successful bot check is not human approval. Visit the pull request for the full picture.

Not reported means no check result is available. Pending means a check has not finished. Action required means a maintainer may need to act. Neutral or skipped checks do not count as passes.

The one-line explanation under each title is written by an AI model reading the item's real comments. It is a best-effort summary and may sometimes be wrong or incomplete. It is not a human's judgment.
